# Hackpad

A 9-key macropad in a 3x3 layout, built around a Seeed Studio XIAO. Each switch has a 1N914 diode for proper N-key rollover, and the board is wired as a 3x3 matrix. ⚠️ (Firmware/Software hier ergänzen)

## Case:

The case holds the PCB in a recess, with a cutout for the USB-C port on the XIAO and an opening for the 4-pin header. ⚠️ (Schrauben/Inserts ergänzen, z.B. "Everything is connected by four M3x16mm screws and M3x5mx4mm heatset inserts.")
